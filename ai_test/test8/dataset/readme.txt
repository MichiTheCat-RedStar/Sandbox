Для более удобной работы было сделано название файлов таким, чтобы по нему было ясно что внутри:

synthetic_* - синтетические данные, сгенерированные более большой ИИ для эксперементального обучения маленькой.

*_data_* - указывает на то, что внутри данные для функции ReadTextData(), то есть текст-текст. Формат: '<usr> запрос <ai> ответ'

*_train_* - указывает на то, что внутри данные для функции ReadTeachData(), то есть текст-число. Формат: '<data> запрос <fact> ответ'

*_cleardata_* - указывает на то, что внутри данные для функции ReadIntData(), то есть число-число. Формат: '<in> запрос <out> ответ'

*_unstandsrt - указывает на то, что данные написаны не по актуальному стандарту.
