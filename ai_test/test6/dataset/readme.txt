Для более удобной работы было сделано название файлов таким, чтобы по нему было ясно что внутри:

synthetic_* - синтетические данные, сгенерированные более большой ИИ для эксперементального обучения маленькой.

*_data_* - указывает на то, что внутри данные для функции ReadData(), то есть текст-текст.

*_train_* - указывает на то, что внутри данные для функции ReadTeachData(), то есть текст-число.

*_cleardata_* - указывает на то, что внутри данные типа число-число, чтобы легко встроить в обучение сразу.

*_unstandsrt - указывает на то, что данные написаны не по актуальному стандарту.
