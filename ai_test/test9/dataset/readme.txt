Для более удобной работы было сделано название файлов таким, чтобы по нему было ясно что внутри: <тип_входа>-<тип_выхода>_<категория>_<название>.jsonl



	- тип_входа -

txt-* - текстовые данные для входа.

vec<N>-* - данные в виде списка чисел, где <N> указывает на количество элементов.

num-* - данные в виде любого числа.


	- тип_выхода -

*-txt_* - ответ, выход, на входные данные в виде текста.

*-num_* - данные в виде числа.

*-bool_* - число 0, 1 или в диапозоне между ними.


	- категория -

*_synt_* - данные были сделаны искуственно, через старшую/большую нейросеть.

*_alg_* -  данные были сделаны через алгоритм, обычно математические функции.

*_hand_* - данные были сделаны вручную.

*_comb_* - данные сделаны с помощью комбинирования разных подходов


	- название -

*_<Name> - обычное название с использованием букв ASCII, так же допускаются числа, где вместо <Name> само название.



Внутри файл записывается в формате JSONL:
```jsonl
{"in": <входные данные>, "out": <выходные данные>}
{"in": <входные данные>, "out": <выходные данные>}
...
```

Первой строкой записывается пометка о типе данных:
```jsonl
{"in": "txt"|"vec5"|"num", "out": "txt"|"num"|"bool"}

{"in": ...
```

Так же допускается использоване '#' для комментариев, но только если он стоит в начале строки.
