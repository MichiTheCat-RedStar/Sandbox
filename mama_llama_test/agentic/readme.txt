Агент для локальных моделей Ollama

Монолитный проект, который изначально был создан под маленькие модели, но в актуальный момент создаётся для более крупных моделей (3B-7B вместо 0.5B-1.5B до этого)

Работает от одного agentic.py файла в директории с собой создавая agent_space/ и data/, где:
	agent_space/ - пространство агента, куда он может записывать и читать файлы
	data/ - имеет сохранение настроек и истории

Так же доступны команды (help|quit|send|task|tools|clear|model|save|load|confs), где:
	help  - вывести этот список для справки о командах
	quit  - выйти из программы
	send  - поговорить с ИИ (дать запрос и получить ответ)
	task  - дать задачу ИИ (используется AgentLoop с инструментами)
	tools - посмотреть список инструментов ИИ
	clear - почистить историю диалога с ИИ
	model - задать модель ИИ
	save  - сохранить диалог с ИИ в постоянную память
	load  - загрузить диалог с ИИ из постоянной памяти
	confs - открыть меню настроек переменных окружения (для продвинутых)

Есть валидация вызова инструментов моделей и попытки создать безопасные условия для работы ИИ и Вас!


Зависимости:
Используйте Python 3.10+ (https://www.python.org/)
Используйте Ollama (https://ollama.com/) и ollama-python (pip install ollama)


Советы:
	Удаляйте agent_space/ или data/ целиком, если вам не нужны файлы там, всё восстанавливает свои значения по умолчанию, поэтому не переживайте!
	Для текстовых запрос-ответ без нужды в использовании инструментов лучше использовать команду send, ведь это тратит меньше времени на ответ, так как не загружаются инструменты
	clear чистит историю локально, а не глобально: для удаления истории целиком пишите clear, потом save
