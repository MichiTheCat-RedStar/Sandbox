Монолитный проект, который изначально был создан под маленькие модели, но в актуальный момент создаётся для более крупных моделей (3B-7B вместо 0.5B-1.5B до этого)

Работает от одного agentic.py файла в директории с собой создавая agent_space/ и history, где:
	agent_space/ - папка, из которой может читать другие файлы агент и куда может записывать файлы
	history - сохранение истории в формате JSON

Так же доступны команды (quit|send|task|tools|clear|model|save|load), где:
	quit  - выйти из программы
	send  - поговорить с ИИ (дать запрос и получить ответ)
	task  - дать задачу ИИ (используется AgentLoop с инструментами)
	tools - посмотреть список инструментов ИИ
	clear - почистить историю диалога с ИИ
	model - задать модель ИИ
	save  - сохранить диалог с ИИ в постоянную память
	load  - загрузить диалог с ИИ из постоянной памяти

Есть валидация вызова инструментов моделей и попытки создать безопасные условия для работы ИИ и Вас!

Используйте Python 3.10+
