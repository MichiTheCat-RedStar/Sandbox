Через ZeroTier раздаём ollama в сеть:

```bash
OLLAMA_HOST=<Ваш IP>:<Ваш порт> ollama serve
```


Далее запускаем main.py и тут пишет об введении IP и порта

Вводите их как раз в формате: "<Ваш IP>:<Ваш порт>", куда хотите подключиться


Далее либо у вас возникает ошибка и запрос повторяется, либо вам будут доступны команды:

list - показывает список моделей

send - для формирования запроса

quit - для выхода в предыдущее меню

connect - общение с одной нейросетью


Диалоги хранятся на стороне клиента, отправляясь каждый раз при запросе, поэтому весь сервер на стороне Ollama и у меня нет прослойки, кроме плашки сверху

list покажет все модели для запуска, их имена

send выдаст вопрос: "Какую модель запустить?", а после выбора: "Введите запрос:", после чего сгенерированный ответ отправится в терминал

quit - просто позволит выйти обратно

connect - высокая вещь, которая спросить модель ИИ, после чего создаст переменную для хранения истории - теперь вы полноценный диалог с моделью ведёте через функцию
