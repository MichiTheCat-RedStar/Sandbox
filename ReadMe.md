## Полигон

**Полигон - это место для тестовых модулей, проектов и кода.**

Всегда сталкивался с проблемой того, что я делаю не только проекты, но и всякие модули _тестирую_ и прочее... По итогу был создан этот репозиторий, чтобы хранить тестировать что-то, чтобы не выносить отдельно каждый тест под каждый репозиторий, как было ранее с "[Маленькими проектами](https://github.com/MichiTheCat-RedStar/Small_Projects)", например.
